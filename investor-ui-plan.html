4. API contract

GET /companies

Universe from universe.json, names mapped at render time only.

POST /assessments

Start a run or replay. Streams stages and agent calls over SSE.

GET /assessments/{id}

Final JSON: committee, evidence, metrics, risks, scenarios, Mubit.

GET /agents/{a}/track-record

Accuracy, Brier, model version, latest correction.

GET /health

Data source in use and the stub/NOT RESULTS flag.

Rules kept

No LLM numbers, point-in-time, no live calls in demo, anonymized prompts, disclaimer on every screen.
